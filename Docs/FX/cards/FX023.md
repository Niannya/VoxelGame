# FX023 失败画面转场 · 交付单

| 项 | 内容 |
|---|---|
| 编号 / 优先级 | FX023 · P0 |
| 名称 | 失败画面转场 |
| 制作方式 | 程序表现 |
| 类型 | screen（world = 世界特效 / target = 贴附跟随 / screen = 全屏层） |
| 持续时间 | 1.0 秒 |
| 作用范围 | 0.0 米（半径） |

## 触发条件
失败判定成立 0.9s 后播放（先让玩家看完坍塌），转场结束发 transition_finished

## 清理条件
结束发信号由玩法侧切结算界面；重开必须先 reset()，progress 归 0，画面恢复正常（验收项）

## 接入 API
```gdscript
var t := FxManager.screen("FX023")；t.play()；t.reset()
```

## 实现说明
去饱和 → 暗红压边 → 全黑，三段式；结尾留 0.25s 纯黑给结算界面淡入，避免闪跳。
