# 美术资产空位清单（关卡）

> 一句话：**代码已经把坑挖好了，美术只要往 `assets/level/level_art_theme.tres` 里填资源，
> 不用改一行代码。** 没填的槽位走程序占位（灰方块），玩法照常跑，不会崩。

## 怎么接

1. 打开 `assets/level/level_art_theme.tres`（基于 `LevelArtTheme`）。
2. 按下面表格把资源拖进对应槽位。
3. 场景里 `Renderer` 节点已经引用它；保存即生效。
4. 编辑器会提示缺哪些方块槽（`missing_block_slots()`）。

## 槽位表

| 槽位字段 | 类型 | 期望规格 | 放哪个目录 | 没填时的表现 |
| --- | --- | --- | --- | --- |
| `block_meshes[&"stone_a"]` | Mesh | 1×1×1 立方体，原点居中，朝 +Y | `assets/level/blocks/` | 灰方块 |
| `block_meshes[&"stone_b"]` | Mesh | 同上（稍暗的变体） | `assets/level/blocks/` | 灰方块 |
| `block_meshes[&"bedrock"]` | Mesh | 同上（矿壁边界，不可破坏） | `assets/level/blocks/` | 深灰方块 |
| `block_materials[id]` | Material | 与 mesh 配套；共用一份可省 draw call | `assets/level/blocks/` | 内置纯色 |
| `crack_meshes[0..2]` | Array[Mesh] | 与方块同尺寸的裂纹叠层，由浅到深 3 档 | `assets/level/cracks/` | 方块轻微缩小（占位） |
| `debris_scene` | PackedScene | 破坏碎屑粒子，1 秒内自动销毁 | `assets/level/fx/` | 不播粒子 |
| `break_sound` | AudioStream | 短促碎裂声 | `assets/level/fx/` | 静音 |
| `rail_mesh` | Mesh | 单格轨道（枕木+钢轨），1 格长，原点居中 | `assets/level/track/` | 无（还没接渲染） |
| `support_mesh` | Mesh | 支撑柱，1×1 底面积，**高度按需拉伸到顶层** | `assets/level/supports/` | 无（还没接渲染） |
| `cart_mesh` | Mesh | 矿车整车，原点在车厢地面中心 | `assets/level/cart/` | 现在的 BoxMesh 平台 |
| `cart_material` | Material | 矿车材质 | `assets/level/cart/` | 默认材质 |

## 命名约定（方便程序找资源 / 以后做批量导入）

```
assets/level/blocks/block_stone_a.glb
assets/level/blocks/block_stone_b.glb
assets/level/blocks/block_bedrock.glb
assets/level/cracks/crack_01.glb   crack_02.glb   crack_03.glb
assets/level/track/rail_01.glb
assets/level/supports/support_01.glb
assets/level/cart/cart_01.glb
assets/level/fx/debris.tscn        break_stone.ogg
```

## 三条硬要求

1. **方块必须是 1×1×1、原点在中心**。程序按格子中心摆实例，尺寸不对会出现缝。
2. **不要给方块 mesh 加碰撞体**。挖掘走体素 DDA，不依赖物理；加了会挡玩家。
3. **裂纹是叠层不是替换**：同位置再盖一层，所以要和方块同尺寸、贴面稍外扩
   （建议 +0.005），否则会闪面。

## 还没接渲染的部分

`rail_mesh` / `support_mesh` / `cart_mesh` 三个槽位**已经在数据结构里预留**，但
L03 的轨道、L04 的矿车外观目前还是程序占位（BoxMesh）。等这两个模块的渲染接进来，
槽位不用改，接线即可——这也是把它们提前定义好的原因。
