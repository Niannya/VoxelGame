# 关卡接口契约（L01～L07 ↔ 玩家 / UI）

> 给其他模块负责人**和他们的 agent** 看。看完这份就能接，不需要读关卡实现。
> 变更规则：改人先改这份文档，再改代码。

## 0. 你会用到的节点

场景根：`res://scenes/levels/level_sandbox.tscn`，根节点类型 `LevelRoot`。

| 节点 | 类型 | 你拿它干什么 |
| --- | --- | --- |
| `Grid` | `LevelVoxelGrid` | 提交挖掘、查询方块 |
| `MineCart` | `LevelCartController` | 读停车原因、站位尺寸 |
| `LevelState` | `LevelState` | 读深度/推进（只读） |
| `Track` | `LevelTrackService` | P06 工程操作查轨道 |
| `Stability` | `LevelStabilityService` | 读矿段稳定度、搭柱 |

**不要**用 `get_node("Grid")._cells` 这类内部字段；下面列的方法才是接口。

## 1. 挖掘提交（P03 / P04 用）

```gdscript
var results: Array = grid.apply_mining(cells, power, miner)
# cells: Array[Vector3i]  —— 本次挥击覆盖的格子
# power: {"stone": 1.0, "ore": 0.5}  —— 破岩词条，缺键回退 "default"
# miner: Node  —— 谁挖的（给掉落归属和事件用）
# 返回: [{cell, destroyed, ratio, drops}]
```

- `ratio` 是 0～1，表现层用它换裂纹档位；`destroyed=true` 时 `drops` 有 0 或 1 件。
- 需求案里"多格工具逐格独立结算"由这个方法保证，你不要自己循环调 `break_block`。
- 想拿掉落数量别读 `results[i].drops` 去加钱——掉落归属走 `block_broken` 信号，金币走 L06。

| `depth_changed(depth, progress)` | LevelState | `int, int` | U01、L06 商店深度 |
| `descend_started(from, to)` | LevelState | `int, int` | U06 流程界面 |
| `cart_blocked(reason)` | MineCart | `StopReason` | U01/U03 提示"谁去处理" |

## 3. 停车原因（L04）

```gdscript
enum StopReason { NONE, ROCK, RAIL, DEBRIS, DESCEND }
```

| 值 | 含义 | 谁负责解除 |
| --- | --- | --- |
| `ROCK` | 前方还没清岩 | P04 挖开 |
| `RAIL` | 轨道没铺好（清岩后 0.25s 施工延迟） | L03 自动完成 |
| `DEBRIS` | 落石堵路（**暂未实现**，当前不会出现） | L03 清理 |
| `DESCEND` | 下潜过渡（**暂未实现**） | L02 |

`cart.blocking_cells()` 给出具体挡路格，`cart.current_reason_text()` 给中文文案，UI 直接拿。

## 4. 只读查询

```gdscript
grid.has_block(cell) -> bool
grid.block_id_at(cell) -> StringName
grid.cell_depth(cell) -> int           # 该格属于第几层（掉落按它结算）
grid.progress_ratio(cell) -> float     # 0～1，裂纹
grid.is_blocked_at(center, half_w, half_d, y_min, y_max) -> bool
grid.solid_cells_in(...) -> Array      # 具体是哪几块
grid.raycast_block(origin, dir, max_dist) -> {hit, pos, normal}

state.depth / state.progress / state.floor_progress()
state.floor_length(d) / state.descent_point(d)
state.depth_at_z(z) / state.depth_at_progress(p)
# 里程 0 点由矿车开局绑定（state.set_origin），别的模块只读不写

track.is_track_ready(center, half_w, half_d) -> bool
stability.value_of(segment) -> float
stability.coverage_ratio(segment) -> float   # 0 = 全覆盖，1 = 完全没护
economy.coins -> int
```

## 5. 从旧接口迁移（重要）

旧场景 `mine_playground.tscn` 里，玩家侧 `mining_controller.gd` 直接调 `VoxelWorld` 的三个方法。
新骨架 `LevelRoot` **保留了这三个方法**做兼容层，所以你**现在什么都不用改**：

| 旧调用 | 兼容层状态 | 迁移到 |
| --- | --- | --- |
| `world.raycast_block(o, d, dist)` | ✅ 保留 | `grid.raycast_block()`（同名同签名） |
| `world.break_block(cell)` | ✅ 保留（秒破，不带进度） | `grid.apply_mining([cell], power, miner)` |
| `world.is_blocked_at(...)` | ✅ 保留 | `grid.is_blocked_at()` |
| `world.block_broken(pos, key)` 两参信号 | ✅ 由 LevelRoot 转出 | `grid.block_broken(cell, block_id, drops)` 三参 |
| `world.update_cutaway(c, h)` | ⚠️ 空实现 | 剖面已由渲染层接管，直接删调用 |

**建议的迁移动作**（玩家侧负责人做）：
1. 把 `break_block` 换成 `apply_mining`，这样才有挖掘进度/多格/破岩词条。
2. 把两参 `block_broken` 换成三参，`drops` 交给背包（P02）。
3. 删掉 `update_cutaway` 调用。

兼容层约定：**等 `mining_controller.gd` 不再调用这三样，就能从 `level_root.gd` 删掉**，
删之前请在本文档勾掉对应行。

## 6. 事件接入方式（L07）

别的模块只上报"发生了什么"，判定归 L07：

```gdscript
event_router.trigger(16, {"room": "diamond", "cell": cell})   # 例：挖开矿物房
```

目前已登记 16 个编号（见 `event_router.EVENT_NAMES`），但**只有编号和状态容器，
判定条件与效果尚未实现**——在 `Docs/Dev/关卡缺口清单.md` 里逐条列明。

## 7. 给 UI 的两条纪律

- 需要什么状态就听信号 + 读只读属性，**不要在 UI 里算掉落、算里程、算稳定度**。
- 数值展示用 `String` 自己拼，但别改数据源。
