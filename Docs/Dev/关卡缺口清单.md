# 关卡缺口清单（已实现 / 未实现）

> 目的：别让任何人（包括 agent）误以为"文档里写过 = 代码里有"。
> 每次合入功能就更新这里，**不更新视为没做完**。

统计口径：L01～L07 逐条对照需求案。

## L01 矿洞格子与掉落

**已实现**
- 18 件物品表 × 第 1～8 层权重（单层 100,000 整数权重），高价档 600→1200 递增、西瓜皮补差
  （`loot_data_l01.gd`，自检断言单层合计与期望值 8.455 / 9.061）
- 每格按**所属深度**抽 1 件基础掉落；多格工具逐格独立结算；边界方块不可挖
- 挖掘进度累加（`hardness` 阈值）、进度比例信号、破坏信号
- 体素 DDA 拾取（不依赖碰撞体）、通行包围盒查询
- 矿物房专用掉落表 `build_mineral_room()`

**未实现**
- 2D 掉落图标弹出 + 飞向背包 + 入包（P02 / UI 侧）
- 背包满时落地成为可拾取实体
- 射击/爆破的破岩词条接入（等 P05）
- 富矿发现、额外掉落（等 L07）
- 矿物房房型的"房内只掉一种矿"实际接线（表已备，房间还没生成）

**验收**：`level_selftest` 的掉落/挖掘用例；需要人工时抽 1000 格统计各类占比。

## L02 房间与推进

**已实现**
- 深度/累计推进/下潜点（`25×d×(d+1)`）/层长（`50×d`）/最远位置只增不减
- 生成时按 z 给每格打深度标
- `progress_changed` / `depth_changed` / `descend_started` 信号

**未实现**
- 随机房间（9×12）预留、挖开入口后显现
- 跨层场景切换/下潜过渡（`DESCEND` 停车原因还是空的）
- 押运交付房、商人相遇点
- 生成器长度仍是固定 40 格，还没按"本层 50×d 格"生成长矿道

## L03 轨道、支撑与稳定度

**已实现**
- 主路清岩后自动铺轨（0.25s 施工延迟）、起始空腔预铺旧轨、回收接口 `reclaim()`
- 每 5 格划分结算段；衰减 `2 + 0.5×(d−1)` 点/秒；30 点预警；归零坍塌信号
- 柱子覆盖边长按深度递减（6→1）、搭柱 +20、重复覆盖不加分
- `is_track_ready()` 给 L04 查询

**未实现**
- 未覆盖比例精确化（现在用"已覆盖格 / 已清格"近似）
- 丧尸聚集扣减、热武器开火扣减
- 落石实体、清理流程、`DEBRIS` 停车原因
- 拆轨产木（2 根/格）、3 木合 1 柱、材料入包（P02）
- 轨道/支撑的实际渲染（美术槽位已留）

## L04 矿车

**已实现**
- 沿 −Z 自动前进，速度可配（默认 1 格/秒）
- 两种停车原因：`ROCK`（未清岩）、`RAIL`（轨道未就绪）
- `blocking_cells()` 给出挡路格、`current_reason_text()` 给文案
- 里程通过 `LevelState.advance_to()` 上报；`deck_half_width/depth` 供玩家站台使用

**未实现**
- 车体真实规格（需求案 6×9 格，现在 2.8×3.6）
- `DEBRIS` / `DESCEND` 两种停车原因
- 车尾过轨回收判定
- 两个炮台挂点、车载熔炉交互位
- 车体/矿车渲染（美术槽位已留）

## L05 丧尸

**已实现**
- 五档概率表的数值（`NORMAL_BANDS`）、两路独立判定、工头独立概率
- 层尾保底名额 `2×d`、保底起点（本层长度−10）

**未实现**
- 丧尸场景/寻路/追击/接触伤害/受击/死亡（整条运行时链路）
- 尸潮窗口（15 秒分批）、在场数量上限、暂停常规补怪
- 与 P08 的接触结算、与 L03 的"段内活怪数"上报

## L06 熔炉与商人

**已实现**
- 共享金币、按基础价卖矿、扣钱、`coins_changed` / `sale_settled`
- 单件加价扩展点 `apply_sale_modifier()`

**未实现**
- 厌食 / 自助餐 / 点菜 / 收购热潮的连击计时与取最优惠规则
- 商人货架（2+2+2）、按深度抽档次、折扣、售罄
- 押运任务、借两根枕木
- 投炉界面（U04）

## L07 随机事件

**已实现**
- 16 个事件编号与名称表、触发次数记录、本局状态容器（钱包/押运/借料/尸潮标记）

**未实现**
- 全部事件的判定条件与效果（每一项都要单独接）

## 建议的下一步顺序

1. **L02 房间 + 长矿道**（决定 L01 能否按 50×d 生成，影响所有人）
2. **L05 丧尸运行时**（要 P08 配合，越早对齐接口越好）
3. **L03 落石/拆轨产木**（接 P06 工程操作）
4. **L06 熔炉事件**（数值先按需求案，接 U04）
5. **L07 逐条事件**（最后做，依赖前面所有信号）
