# 《胡闹矿洞》功能模块分工

## 玩家模块

| 编号 | 功能 | 负责内容 | 与其他功能的交接 |
| --- | --- | --- | --- |
| P01 | 移动系统 | 行走、转向、碰撞。处理搬运木材减速和向外拉长绳索时的移动限制。 | 接收 P02 的搬运状态和 P07 的绳索约束，统一计算实际移动。 |
| P02 | 背包与搬运 | 携带和切换矿镐、冷兵器、热武器、工程锤。拾取、放下、投掷或交接物品。 | 向 P01 提供当前搬运状态，向 P03 提供当前工具，向 U02 提供背包状态。 |
| P03 | 工具操作 | 根据工具、朝向和瞄准格计算一次操作的覆盖范围。管理出手间隔、范围挥镐的横竖切换和长刀的两格范围。 | 同一次挥击的覆盖范围交给 P04 挖掘、P05 攻击和 U03 预览。 |
| P04 | 挖掘系统 | 根据覆盖范围和工具的破岩词条，计算这次操作对各矿格的挖掘效果。 | 向 L01 提交受影响的矿格和挖掘进度。刀具也能挖矿，使用刀具自身的破岩效率。 |
| P05 | 攻击系统 | 冷兵器负责普通挥砍、长刀。热武器负责射击、分裂、贯穿和爆破。 | 按工具对应的攻击词条处理怪物命中。爆破弹对可采岩块的效果交给 P04 和 L01。 |
| P06 | 工程操作 | 使用工程锤铺轨、拆轨、搭支撑。负责选格、批量预览和施工计时。 | 向 L03 查询施工是否合法，完成后由 L03 更新轨道、支撑和材料。 |
| P07 | 绳索系统 | 全队共用一个可移动绳结，每名玩家一条分支。每条分支按绳结到玩家的距离单独计算，6 格为松弛阈值，8 格为上限。负责合力、绳结移动和倒地拖拽。 | 给 P01 提供移动约束。从 P08 读取倒地状态，给 U03 提供每条分支的受力状态。 |
| P08 | 生命与救援 | 管理玩家扣血、治疗、免伤、昏厥和复苏。 | 接收 L05 的受击请求。P07 把倒地玩家拖到队友附近后，由 P08 判断能否复苏并更新进度。 |
| P09 | 个人天赋 | 获得天赋后立即生效，管理持续时间、剩余次数和到期。 | 接收 L07 发放的天赋。范围挥镐改 P03 的覆盖范围，轻装搬运改 P01 的移动状态。U05 读取剩余时间和次数。 |

## 关卡模块

| 编号 | 功能 | 负责内容 | 与其他功能的交接 |
| --- | --- | --- | --- |
| L01 | 矿洞格子 | 管理岩石、矿物、空地和边界。记录每格挖掘进度，破岩后更新通路并生成掉落。 | 接收 P04 的挖掘请求。给 L04 提供通路状态，给 L07 提供挖矿和掉落结果。 |
| L02 | 房间与推进 | 拼接矿道、生成房间、进入下一段或下探。提供矿物房和押运任务的接收、交付房间。 | 给 L07 提供进入房间和离开房间的时机。给 U06 提供开局、失败结算和重开的局内状态。 |
| L03 | 轨道与稳定度 | 保存轨道、支撑和工程材料变化。判断铺、拆、搭的位置是否合法，处理稳定度与坍塌。 | 给 P06 返回施工结果，给 L04 提供轨道状态，给 U01 和 U03 提供稳定度及施工预览信息。 |
| L04 | 矿车 | 根据前方通路和轨道状态控制行进与停车。后续车体和炮台改装也挂在矿车上。 | 从 L01 查询前方是否清岩，从 L03 查询是否已铺轨。车载熔炉的交易结算交给 L06。 |
| L05 | 丧尸 | 生成丧尸，处理寻路、追击、攻击、受击和死亡。 | 接收 P05 的命中结果。击中玩家时交给 P08，丧尸死亡后把击杀结果交给 L07。 |
| L06 | 熔炉、商人与经济 | 投炉售矿、共享金币、商人货架、购买、折扣和借还木料。统一处理发钱、扣钱和发货。 | 接收 U04 的购买或借还请求，读取 L07 的事件结果，例如下次交易的折扣。 |
| L07 | 随机事件 | 处理先后事件、击杀丧尸、幸运方块和挖矿爆出四种主要触发方式。记录钱包是否归还、押运进度、矿贼被放跑次数等本局状态。 | 需要发个人天赋时交给 P09，需要改金币和交易时交给 L06，触发结果交给 U05 显示。 |

## UI 模块

| 编号 | 功能 | 负责内容 | 与其他功能的交接 |
| --- | --- | --- | --- |
| U01 | 局内 HUD | 显示血量、倒地与复苏进度、共享金币、稳定度和当前工具。 | 读取玩家、经济和关卡的实际状态。 |
| U02 | 背包与快捷栏 | 显示工具、物品和当前选中槽位。 | 读取 P02 的背包状态，给 P02 发出切换工具或使用物品的请求。 |
| U03 | 操作预览与提示 | 显示横挖、竖挖、长刀覆盖格、铺轨和支撑预览，以及哪条绳在拉紧。 | 使用 P03 返回的覆盖格、L03 返回的施工合法性，以及 P07 返回的分支状态。 |
| U04 | 商店与任务界面 | 显示货架、折扣、借还木料、押运进度和交付奖励。 | 购买与借还由 L06 结算。押运进度和交付结果由 L07 提供。 |
| U05 | 事件与天赋提示 | 显示发生了什么、效果给了谁、还剩几秒或几次。 | 读取 L07 的触发结果和 P09 的天赋状态。例如显示熔炉厌食的矿种和解除办法。 |
| U06 | 流程界面 | 组队、开始、暂停、失败结算和重开。 | 发送流程操作请求，按局内状态显示对应界面。 |
