# 《胡闹矿洞》L03 轨道回收与矿洞支撑

**玩法流程**　挖开主路 → 自动生成轨道 → 矿车通过 → 用工程锤拆旧轨 → 木头自动合成柱子 → 在矿道两侧加固。矿道越深，柱子护住的范围越小，未加固处的稳定度掉得越快。

## 1. 轨道、木头与柱子

| 环节 | 规则 |
| --- | --- |
| 轨道生成 | L01 确认主路某格的矿车通行空间已经清空，L03 立即在该格自动生成轨道。沿用主路规划，侧洞等非矿车线路不出轨。 |
| 回收旧轨 | 整个车尾通过后，才能用工程锤拆该格旧轨。拆 1 格轨道产出 2 根木头。每格只生成和回收一次。 |
| 自动合成 | 同一玩家背包每凑齐 3 根木头，自动合成 1 根支撑柱。剩余木头保留。例如拆 2 格获得 4 根木头，合成后剩 1 根柱子和 1 根木头。 |
| 搬运与交接 | 玩家可以接力搬木头或成品柱。工程锤的首版操作是拆轨与搭柱。 |
| 放置支撑 | 在合法支撑位使用工程锤，消耗 1 根成品柱。柱身从当地地面伸到顶层下沿，自动适配实际高度。顶层更高时也使用 1 根柱子。 |
| 起步供应 | 开局时在矿车后方预留可回收旧轨。首测可先留 3 格，对应 6 根木头，足够搭左右一对柱。L02 生成后续通道时也要检查车尾是否有可回收储备。 |

## 2. 柱位与覆盖

主矿道两侧预留合法柱位，避开轨道和矿车净空。浅层以**每隔 5 格左右各搭一根**作为基础布局。深层可以加密柱位或优先补危险区。放置前显示单根柱的地面覆盖边界和两侧柱之间剩余的空缺，叠加覆盖按格去重。

单根柱子的范围是**地面格上的正方形**，高度另按当地地面和顶层决定。首测让左右两侧的柱子朝矿道内侧覆盖。柱子范围按柱位所属深度确定，沿用 [L02 房间推进与矿洞深度](胡闹矿洞L02房间推进与矿洞深度.md) 的层级。

| 矿洞深度 | 单根柱子覆盖 | 未支撑时的基础时间衰减 |
| --- | ---: | ---: |
| 第 1～2 层 | 6×6 格 | 第 1 层 2 点／秒，第 2 层 2.5 点／秒 |
| 第 3～4 层 | 5×5 格 | 第 3 层 3 点／秒，第 4 层 3.5 点／秒 |
| 第 5～6 层 | 4×4 格 | 第 5 层 4 点／秒，第 6 层 4.5 点／秒 |
| 第 7～8 层 | 3×3 格 | 第 7 层 5 点／秒，第 8 层 5.5 点／秒 |
| 第 9～10 层 | 2×2 格 | 第 9 层 6 点／秒，第 10 层 6.5 点／秒 |
| 第 11～12 层 | 1×1 格 | 第 11 层 7 点／秒，第 12 层 7.5 点／秒 |
| 第 13 层起 | 首测保持 1×1 格 | 继续按每深入一层增加 0.5 点／秒结算 |

即**每深入两层，正方形边长减 1 格**。例如需要保护的通行带宽为 9 格，左右柱各覆盖 4 格时，中间仍有缺口。前后柱距为 5 格、单柱只覆盖 4 格长时，也会留下缺口。覆盖以预览中的格子为准。

## 3. 矿段稳定度

按主路**每 5 格**划分一个稳定度结算段。矿洞仍未开挖时不计时。首测在该段第一次出现清开的主路格时激活稳定度，初始值与上限均为 **100 点**。只对当前玩法范围内已激活的矿段更新状态，每段独立结算。

| 因素 | 首测规则 |
| --- | --- |
| 开挖后随时间衰减 | 第 `d` 层的基础衰减为 `2 + 0.5 × (d − 1)` 点／秒。实际扣减乘上未覆盖比例，即该段已开挖且需要保护的格子中，尚未被柱子护住的比例。全覆盖后，这一项为零。 |
| 搭建柱子 | 每根柱子为某段带来新的有效覆盖时，该段的**稳定度和上限各加 20 点**，柱子的覆盖持续有效。同一根柱子对同一段只结算一次，重复覆盖已有格子不加分。 |
| 丧尸聚集 | 只统计矿段内活着的丧尸。前 2 只不增加扣减，第 3 只起每只额外扣 0.3 点／秒，每段最多扣 1.8 点／秒。丧尸离开或被击败后，扣减随数量降低。 |
| 热武器开火 | 每轮开火使开火者所在段扣 0.2 点。分裂成几条弹道仍算同一轮。爆破命中时可另外对实际受影响的每段扣 1 点，同一爆炸在同一段只扣一次。 |
| 危险预警 | 稳定度降到 30 点及以下时，标出危险矿段，并播放落灰和裂缝。实际预警余量取决于当前衰减速度，首测检查玩家是否来得及补柱。 |
| 局部坍塌 | 稳定度到 0 时，在本段生成局部落石。落石占住通路时矿车停车，玩家可以清理并补支撑。落石本身不产出普通掉落。 |

**例子。**第 5 层某段有一半格子未覆盖，时间项每秒扣 2 点。如果段内还有 5 只丧尸，额外每秒扣 0.9 点。枪手再开火时，按每轮射击另扣。工程师补柱能立刻抬高稳定度并减少后续时间衰减，近战也可以接手把怪清走。

首测建议将坍塌标为待处理状态，同一处落石清理结束前只生成一次。清开落石并确认该段有有效支撑后，解除待处理状态，稳定度至少恢复至 30 点，再按正常规则结算。局部坍塌造成的阻挡由 L04 检查，已计入的矿车推进里程由 L02 保留。

## 4. 与 L02 和其他模块的交接

| 模块 | 交接 |
| --- | --- |
| L02 房间与推进 | 提供主路格子、矿段深度、房间边界及合法柱位。每 5 格结算段不得跨深度。下潜后按新矿段深度计算新柱覆盖和时间衰减。 |
| L01 矿洞格子 | 主路清岩后通知 L03 生成轨道。L03 局部坍塌后，L01 接收落石阻挡并负责其清理。 |
| L04 矿车 | 提供车尾已通过的位置供拆轨判定，并根据清岩、轨道与落石状态控制通行。 |
| P02 背包、P06 工程操作 | P02 处理木头入包及自动合成。P06 提交拆轨或搭柱的位置。 |
| L05 丧尸、P05 攻击 | 分别提供矿段内活跃丧尸数量，以及开火和爆炸发生的位置与轮次。 |
| UI | 显示可拆旧轨、柱位、覆盖范围、矿段稳定度和坍塌预警。 |
