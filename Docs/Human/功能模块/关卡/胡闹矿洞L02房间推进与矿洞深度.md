# 《胡闹矿洞》L02 房间推进与矿洞深度



## 1. 深度和推进格数

- 每局从**第 1 层、累计推进 0 格**开始。
- 首测按每层多走 **50 格**设计。第 1 层走 50 格，第 2 层再走 100 格，第 3 层再走 150 格。第 `d` 层的长度是 `50 × d` 格，通往下一层的累计下潜点是 `25 × d × (d + 1)` 格。
- **推进只看矿车沿主路线到达的最远位置。**停车、倒退后驶回旧位置、玩家离车探索和挖掉侧墙都不会增加推进格数。场景切换或下坠的垂直位移也不计入主路线。
- **挖开几个方块与矿车走了几格分别记录。**矿车前进 1 格可能要清掉多格岩块。前者用来换层，实际破碎的方块数决定掉落抽取次数。

| 当前层 | 本层主路长度 | 累计推进区间 | 下潜到下一层的位置 | 本层高价档合计掉率 |
| --- | ---: | --- | ---: | ---: |
| 第 1 层 | 50 格 | 0 ≤ 推进 < 50 | 50 格 | 0.60% |
| 第 2 层 | 100 格 | 50 ≤ 推进 < 150 | 150 格 | 0.70% |
| 第 3 层 | 150 格 | 150 ≤ 推进 < 300 | 300 格 | 0.80% |
| 第 4 层 | 200 格 | 300 ≤ 推进 < 500 | 500 格 | 0.90% |
| 第 5 层 | 250 格 | 500 ≤ 推进 < 750 | 750 格 | 1.00% |
| 第 6 层 | 300 格 | 750 ≤ 推进 < 1,050 | 1,050 格 | 1.10% |
| 第 7 层 | 350 格 | 1,050 ≤ 推进 < 1,400 | 1,400 格 | 1.20% |
| 第 8 层 | 400 格 | 1,400 ≤ 推进 < 1,800 | 1,800 格 | 1.20% |

第 7 层起，高价档保持 **1.20%／格**。各层所需的推进格数继续按递增序列计算。高价档内部比例及西瓜皮的补差规则见 [L01 掉落物经济与概率](胡闹矿洞_L01_掉落物经济与概率.md)。

## 2. 主路、房间和下潜

1. **拼接本层主矿道。**主路的纵向格数按本层目标生成。玩家挖开通路并补齐轨道后，由 L04 驱动矿车前进。侧洞、矿物房和奖励区域可以挂在主路边，留给队伍自行决定是否探索。
2. **分别记录房间和深度。**同一深度可以有多个房间。进入押运接收房、投递房或进入侧面的随机矿物房，都能触发各自的房间事件。只有矿车达到该层的下潜点才会进入新深度。
3. **跨过推进门槛时下潜一次。**例如累计推进从 49 格到 50 格时，触发进入第 2 层。L02 记录本层已结束，准备下一层入口，下潜完成后切换当前深度并刷新本层进度为 `0 / 100 格`。累计推进仍为 50 格。停在边界或反复穿过同一位置时不会重复下潜。
4. **保留本局状态。**玩家背包、共享金币和仍有效的事件记录跟随队伍进入下一层。限时天赋继续按原规则计时。已挖开或已获得的物品保持原结算。

## 3. 深度如何影响掉落与经济

- L02 生成矿段或房间时给它标记所属深度，L01 破岩时读取这个标记。例如第 2 层入口挖出的方块按第 2 层掉率抽；若还能回头挖第 1 层的旧墙，旧墙仍按第 1 层结算。一次挥击覆盖分界两边时，各格分别按所属层抽取。
- 深度低保通过提高高价档概率抬高平均收入。同一种物品的基础售价在各层一致。一层走到头仍可能没出大奖，试玩要记录这种局面的实际收入能否覆盖正常推进开支。
- 回收轨道、支撑消耗、投炉和购买继续由原模块结算。L02 提供深度和推进信息，供各模块后续配置该层的资源、供给或压力。

## 4. 模块交接

| 模块 | 交接内容 |
| --- | --- |
| L04 矿车 | 提供矿车在主路线上的位置，接收本层目标和下一层入口。 |
| L01 矿洞格子 | 使用 L02 提供的矿段和房间深度标记，按对应层抽取基础掉落。 |
| L07 随机事件 | 分别接收进入房间、离开房间和完成下潜的通知，用于矿物房、押运及跨层事件。 |
| UI | 显示当前深度和本层推进，例如「第 2 层 · 37 / 100 格」。下潜时给出简短提示。 |
