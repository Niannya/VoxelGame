# 《胡闹矿洞》L04 矿车行进与改装预留

矿车沿主轨道自动前进。前面的通行空间清开、轨道就绪时就走；遇到岩块或落石时在阻挡前停住。L04 负责矿车的移动、停车原因、车尾过轨和车上挂载位置。

## 1. 基础尺寸与运行

| 项目 | 首版规则 |
| --- | --- |
| 车体尺寸 | 沿轨道长 **6 格**、垂直于轨道宽 **9 格**、高 **1 格**。车体碰撞和矿道通行高度分别配置，通行高度由关卡提供。 |
| 行进方式 | 沿主轨道自动前进，首测速度 **1 格／秒**。路线连续可通行时持续移动。 |
| 通行判定 | 检查下一步车身会扫过的区域，以及前方轨道是否就绪。中间有轨、车身侧边仍有岩块时，矿车也会在阻挡前停下。 |
| 车上站位 | 玩家站在平台上时随车移动，仍可在平台上走动、使用工具和下车。车上保留玩家站位、交接和投炉入口所需的空间。 |
| 车载熔炉 | 熔炉和投炉入口随车移动。玩家进入交互范围时可投炉，物品扣除和共享金币由 L06 结算。 |

## 2. 停车与恢复

| 停车原因 | 处理方式 |
| --- | --- |
| 前方未清岩 | 标出实际挡住车身的岩块。玩家挖开后，L03 按主路规则自动出轨，矿车重新检查并继续前进。 |
| 轨道尚未就绪 | 等待 L03 完成当前主路格的自动出轨。 |
| 落石堵路 | 标出阻挡位置。落石清开、L03 确认该段完成修复后，矿车自动继续。 |
| 下潜过渡 | 到达 L02 的推进门槛后，按关卡过渡流程暂停。新层入口就绪后恢复行进和通行检查。 |

挖开遮挡岩块时，预留的随机房间可以显现。矿车进入房间时继续按通行条件判断。界面优先显示当前实际停车原因和相关挡路格，帮助队伍判断该叫谁过去处理。

## 3. 推进与车尾回收

1. **推进位置交给 L02。**L04 报告矿车在主路线上的实际位置，L02 按最远位置累计里程并判断何时下潜。停车等待期间里程保持。
2. **车尾过轨交给 L03。**判断某格能否回收时，以整个车尾离开该格为准。L04 通知 L03 哪些旧轨已经完全通过，L03 负责可拆标记、拆除和每格产出 2 根木头。
3. **关卡数据交给矿车。**L01 提供岩块与落石阻挡，L03 提供轨道和修复状态，L04 据此执行停车或恢复。已回收的旧轨继续沿用 L03 的一次性规则。

## 4. 炮台位置与后续改装

### 炮台预留位

在车体上预留 **2 处炮台挂点**，建议放在**车尾左侧和车尾右侧**。车尾中间留给队友走动和交接。具体挂点坐标随熔炉位置和车体模型一起调整。

- 每个挂点独立记录位置、朝向和当前是否安装，炮台随车移动。两处可使用同一套炮台资源。
- 预留炮台转向和朝车后开火的空间。布置时检查炮台底座、炮口和转动范围是否挡住炉口、上下车路线或玩家常用站位。
- 首版挂点可以保持空置。后续炮台类型可沿用已有的**冰霜炮台与刀具碎冰**、**火焰炮台与地面火区**两个方向，具体数值在实现改装时再定。

### 矿车升级预留

| 升级方向 | L04 需要预留的内容 |
| --- | --- |
| 动力升级 | 将基础行驶速度做成可配置值，留出动力、负重对速度的修正。实际收益用通畅路段的推进时间验证。 |
| 平台扩容 | 将平台站立范围、车体碰撞和车尾边界分别记录。将来如果车身随升级变宽或变长，同步更新关卡通行检查和车尾可拆轨判定。 |
| 火力改装 | 通过两个炮台挂点安装后续炮台。各类弹药和射击行为由炮台功能负责。 |
| 熔炉改装 | 炉口继续跟随车身。后续如果调整处理速度或回收收益，将对应参数交给 L06 结算。 |

升级的来源、价格和具体效果留到改装系统定稿。L04 首版先保留车体数据、挂点和速度接口，方便后续接入。
