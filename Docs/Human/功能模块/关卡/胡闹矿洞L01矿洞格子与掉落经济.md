# 《胡闹矿洞》L01 矿洞格子、挖掘掉落与经济

L01 负责矿格状态、破岩和基础掉落。P04 提交挖掘操作，P02 接收入包物品，L06 负责投炉和共享金币。[L02 房间推进与矿洞深度](胡闹矿洞_L02_房间推进与矿洞深度.md)提供矿格所属层级，L01 按层级使用对应掉率。

**基本流程**　工具命中矿格 → 累积挖掘进度 → 方块破碎并清开 → 弹出 2D 物品图标 → 自动收入挖开者的背包 → 玩家按需回矿车投炉。

## 1. 方块与状态

| 状态 | 游戏判定 | 画面表现 |
| --- | --- | --- |
| 完整岩块 | 可挖掘，阻挡通行。 | 所有普通可挖方块共用同一个方块模型和基础岩面材质。 |
| 开裂岩块 | 仍然阻挡通行。保留已获得的挖掘进度，其他队友也可以接着挖。 | 进度到达约三分之一、三分之二时分别加深裂纹。裂纹用材质或贴图叠层表现。 |
| 空格 | 挖掘进度达到上限后，格子变空，清除原岩块的阻挡。 | 播放短促的碎裂效果，露出被挡住的通路。 |

- 每格保存坐标、类型、挖掘进度、破岩阈值和所属深度，普通岩块使用对应深度的基础掉落表。首版普通岩块使用同一破岩阈值。空格、不可挖边界和轨道、支撑等工程物分别管理。
- 普通岩块外表不显示内部具体物品。首轮可全用同一种岩面材质，后续再用矿脉反光、锈迹或人工刻痕提示某些区域更值得挖。线索只提示可能有好东西，具体是什么由破岩时的掉落结果揭晓。
- L01 给矿车和施工系统提供实际格子状态。矿车占用范围内的相关格子都清开后，才满足清岩条件。L04 还会检查轨道是否铺好。

## 2. 挖掘与掉落结算

1. P04 提交本次操作的玩家、命中的矿格，以及每个格子增加的挖掘进度。L01 检查格子是否仍然可挖，并给每个有效格子累计进度。
2. 进度达到阈值的那次操作把格子从岩块变为空。L01 在同一次结算中清除阻挡、记录挖开者，再按该格所属深度抽取 **1 件基础掉落**。
3. 多格工具一次可以挖开多个格子。每个实际破碎的格独立抽取一次。没挖穿的格只更新裂纹和进度，已经清掉的格不再抽取。两人同时挖同一格时，按照实际结算顺序处理；只有第一次达到破岩阈值的操作获得掉落。
4. 矿镐、刀具和工程锤使用各自的破岩词条。同一招覆盖多个格时，每格分别吃到挖掘进度。爆破弹可以通过 P04 提交可采岩块，普通枪弹沿用原案的破岩限制。战斗命中由攻击系统处理。
5. 基础掉落结算后，向 L07 发出破岩通知，包含格子、挖开者和掉落物。富矿发现等额外掉落及挖矿触发事件走各自的规则。额外产物不会让同一格再抽一次基础掉落。

## 3. 2D 掉落与入包

- 岩块破碎的位置弹出对应物品的 2D 图标。图标朝向镜头，短暂停留后飞向挖开者，推荐首测表现用时 **0.25～0.4 秒**。稀有物可以多一道闪光或短音效，保持连续挖掘时可读。
- P02 背包系统接收物品并自动堆叠。破岩结算时就尝试入包，画面上的抛出和飞入是一次获得的反馈。基础掉落在空中时不需要玩家走过去捡，也不能被别人抢拾。
- 如果背包实现了容量限制，先合并到现有堆叠。确实装不下时，在破岩位置生成一份可拾取的实体掉落，并提示背包已满。一次掉落只能走入包或落地中的一个分支。
- 遁地矿贼可检查玩家主动放在地上的高价值矿或事件生成的实体矿。普通自动入包过程中的图标不参与抢矿。

## 4. 三类掉落物

每个物品记录名称、编号、类别、2D 图标、堆叠规则和基础售价。售价单位是**游戏金币／件**，售价和掉率均为首测值。

## 6. 经济循环与结算

- **搬运与交接。**玩家可自己把背包里的物品带回矿车，也可交队友代卖。金币在投炉成交时到账。
- **投炉与共享余额。**18 件物品沿用同一个投炉入口。L06 按实际投入的种类和数量核算，基础收入为各物品的 `基础售价 × 数量` 之和。成交后同时扣除物品、增加全队金币。下潜时背包和金币随本局保留，任何深度挖到的同一物品按同一基础价出售。
- **天赋与事件。**月光石、黄金矿块、钻石带天然矿物标签，可参与富矿发现、收购热潮、熔炉点菜和厌食。铀-235 号样本用特殊矿样标签，杂物和古董使用各自类别。押运仍只统计任务发放并标记的矿，途中投炉按表价，送到指定房间按实际交付价值的 2 倍结算。
- **消费。**全队可用共享金币向商人购买补给，后续也可用于矿车改装。商人折扣只作用于购买，钱包事件或其他修正由 L06 在相应交易中结算。先用本表测试队伍能赚多少，再按补给需求确定商店价格。
