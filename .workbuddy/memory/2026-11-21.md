## 破坏方块 + 悬停高亮 + 计数 HUD

- 关键前提：烘焙版的 MultiMesh 没有逐块信息，做不了拾取和破坏。所以新写 `scripts/world/voxel_world.gd`（Node3D）在运行时生成，持有 `grid: Dictionary[Vector3i -> String]`，才能做射线拾取和单块删除。
- 拾取用**体素 DDA 遍历**（Amanatides-Woo），不依赖碰撞体，因此能精确选中方块本身。坐标换算：方块 i 覆盖 `[i-0.5, i+0.5)`，平移 `+0.5` 后正好是 `[i, i+1)`，取 `floor()` 即格号。
- 破坏：`MultiMesh.set_instance_transform` 把该实例缩放到零并挪到 y=-9999（直接减 `instance_count` 会打乱后续下标）。
- 碰撞：只给**暴露在空气里**的方块建 `CollisionShape3D`（共用同一个 `BoxShape3D`），破开后再给新暴露的邻居补上，破掉的移除。
- 地板铺两层（j=-1 / j=-2），挖穿一层能看到下面的岩层而不是虚空。
- 高亮：ImmediateMesh 画 12 条线框 + 一层 `BLEND_MODE_ADD` 的淡填充（fov 拉远后 1px 线框几乎看不见，必须叠填充）。蓄力时颜色从 `(1,0.88,0.32)` 渐变到 `(1,0.32,0.12)`。
- 长按破坏 0.55 秒，破坏时喷 `CPUParticles3D` 碎块。
- HUD：`scenes/ui/mining_hud.tscn`，右下角显示「已挖 N」+ 分矿种统计。
- **新增跳跃**（Space，`jump_velocity = 7.5`）：因为挖掉脚下那块会掉进坑里出不来，按 `v²/(2g)=1.17 格` 定的值，必须能跳上一格。

## 矿车改为移动平台 + 矿道整体堵死 + 未挖方块虚化

- **世界结构变了**：`voxel_world.gd` 删掉侧墙（俯视角挡视野），起始空腔（`chamber_length = 7`）之后整段矿道被矿体填满，玩家必须自己挖通道。空腔尾部有堵墙防止回望看到虚空。
- **矿车** `scenes/world/mine_cart.tscn` + `scripts/world/mine_cart.gd`：`AnimatableBody3D` 平台（2.8 × 3.6，顶面即节点原点）。每物理帧用车身包围盒调 `is_blocked_at()` 探前方，有矿就 `blocked = true` 停住，挖开自动继续。
- **玩家限制在平台上**：`player.gd` 的 `_clamp_to_platform()` 每帧把玩家夹到平台局部坐标的 ±(half - margin) 内。玩家靠平台的速度传递被带着走，实测矿车前进 1.98 时玩家局部坐标几乎不变（0, 0.0001, 0.11）。
- **虚化**：两层 MultiMesh —— 实体层（不透明）和虚化层（alpha 0.32 透明）。`update_ghosting()` 按 z 距离把矿车前后 `ghost_radius` 内的未挖方块从实体层切到虚化层。**必须分两层**：透明材质不写深度，混在一层会让实心矿石也被看穿。
- 摄像机改成近俯视：`(0, 11, 4.5)`，pitch **-64°**，fov 50。
- 挖矿 `break_time` 从 0.55 降到 0.4，因为现在一次要挖 3 宽 × 2 高才能推进一格。

### 踩坑

- GDScript 里**没有 12 参数的 `Transform3D` 构造**（那是 .tscn 序列化格式），`const` 也不能调用 `Basis().scaled()`。零缩放变换只能写成普通成员变量。
- 虚化半径一开始给 6.5，108→324 块全半透明，整屏糊成毛玻璃。降到 4.0 才正常。

### 实测

- 矿车起始 z=3 → 自动前进到 z=1.31 被矿体挡住（`blocked=true`）→ 挖开 z=-1 那排 → 前进 1.98 到 z=-0.67 → 再次被挡。

## 剖面：从「虚化」改成「直接隐藏」（用户纠正）

- 我最初按「矿车前后各 4 格」虚化，把**前方待挖的矿也虚化了**，用户反馈「为什么把所有都虚化了」。
- 正确语义：**矿车进入矿层后**，把它**已经走过的那一段**（前缘往后 `cutaway_behind = 5` 格）里没挖掉的方块处理掉，前方待挖的保持实体。
- 半透明方案彻底失败：矿体 6 格高，俯视 -64° 下要穿 3~6 层，alpha 0.32 直接糊成毛玻璃，降到 0.10 仍是雾。**必须直接隐藏**（零缩放 + 挪到 y=-9999）。
- 全部隐藏会让矿道变成开阔场地。加 `cutaway_min_height = 2`：只隐藏通道顶部，保留 2 格高的两侧矿壁，才有矿道的样子。
- 结果：起点隐藏 0 块（矿车还在空腔），进入矿层后隐藏 180 块（j>=2 那部分）。
